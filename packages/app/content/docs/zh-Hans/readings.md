# 选择读音

很多词有不止一个读音。市場 可以读作 いちば 或 しじょう，今日 可以读作 きょう 或 こんにち。Furifont 显示最常见的读音。要显示其他读音，就在词的第一个汉字后面紧跟一个变体选择器。

变体选择器是看不见的字符。它留在文本中，所以在使用这款字体的任何应用和网站上都有效，复制文本时也会保留。

## 选择器

| 选择器 | 码位 | 效果 |
| --- | --- | --- |
| VS225 | U+E01E0 | 无振假名 |
| VS226 | U+E01E1 | 读音 1，即默认读音 |
| VS227 | U+E01E2 | 读音 2 |
| VS228 | U+E01E3 | 读音 3 |
| … | … | … |
| VS240 | U+E01EF | 读音 15 |

放在词的第一个汉字后面时，选择器选的是这个词的读音。放在单独一个汉字后面时，选的是这个汉字的读音。

::docs-example{text="市場"}
::

::docs-example{text="市\u{E01E2}場"}
::

::docs-example{text="今\u{E01E2}日"}
::

::docs-example{text="今\u{E01E0}日"}
::

## 查找读音编号

[参考](/reference) 按顺序列出了所有有多个读音的词和汉字。在那里点击读音，即可复制带选择器的词。

每个版本也以数据形式提供这些列表：`FurifontSansVF.ivs.json`，以及每个字体家族对应的同类文件。

## 输入选择器

变体选择器无法用键盘输入。可以从 [参考](/reference) 复制，或写成转义形式：

| 位置 | 市 + VS227 + 場 的写法 |
| --- | --- |
| HTML | `市&#xE01E2;場` |
| JavaScript | `'市\u{E01E2}場'` |
| CSS `content` | `'市\E01E2場'` |

其他字体会忽略这些选择器，所以文字在它们中看起来不变。

## 选择器还是 CSS？

选择器会改变文本。搜索和复制时会多出一个字符，有些工具也会把它计入字数。在网站上，可以改用 CSS 选择读音，文本保持原样：

```html
<span style="font-feature-settings: 'salt' 2">市場</span>
```

`'salt' 2` 的效果与 VS227 相同。请参阅 [在网站上使用](/docs/website#choose-a-reading)。
