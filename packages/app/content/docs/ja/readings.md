# 読みを選ぶ

読みが複数ある言葉はたくさんあります。市場は「いちば」とも「しじょう」とも読み、今日は「きょう」とも「こんにち」とも読みます。Furifont は、一番よく使う読みを表示します。別の読みにするには、言葉の最初の漢字のすぐ後ろに異体字セレクタを置きます。

異体字セレクタは目に見えない文字です。文章の中に残るので、フォントを使うどのアプリでも、どのウェブサイトでも働きます。文章をコピーしても消えません。

## セレクタの一覧

| セレクタ | コードポイント | 結果 |
| --- | --- | --- |
| VS225 | U+E01E0 | ふりがななし |
| VS226 | U+E01E1 | 読み 1（既定） |
| VS227 | U+E01E2 | 読み 2 |
| VS228 | U+E01E3 | 読み 3 |
| … | … | … |
| VS240 | U+E01EF | 読み 15 |

言葉の最初の漢字の後ろに置くと、セレクタはその言葉の読みを選びます。一つだけの漢字の後ろに置くと、その漢字の読みを選びます。

::docs-example{text="市場"}
::

::docs-example{text="市\u{E01E2}場"}
::

::docs-example{text="今\u{E01E2}日"}
::

## 読みの番号を調べる

[リファレンス](/reference) には、読みが複数ある言葉と漢字が、読みの順にすべて載っています。そこで読みをクリックすると、セレクタ付きの言葉をコピーできます。

各リリースには、この一覧をデータとしたファイルも付いています。`FurifontSansVF.ivs.json` と、ほかのファミリーの同じファイルです。

## セレクタを入力する

異体字セレクタはキーボードでは入力できません。[リファレンス](/reference) からコピーするか、エスケープで書きます。

| 書く場所 | 市 + VS227 + 場 の書き方 |
| --- | --- |
| HTML | `市&#xE01E2;場` |
| JavaScript | `'市\u{E01E2}場'` |
| CSS の `content` | `'市\E01E2場'` |

ほかのフォントはこのセレクタを無視するので、見た目は変わりません。

## セレクタか CSS か

セレクタは文章そのものを変えます。検索やコピーでは余分な文字が一つ入り、それを文字数に数えるツールもあります。ウェブサイトでは、代わりに CSS で読みを選べます。その場合、文章はそのままです。

```html
<span style="font-feature-settings: 'salt' 2">市場</span>
```

`'salt' 2` は VS227 と同じ働きをします。[ウェブサイトで使う](/docs/website#choose-a-reading) を見てください。
