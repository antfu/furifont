# フォントのインストール

Furifont をパソコンにインストールすると、フォントを選べるアプリならどれでも使えます。ワープロ、デザインツール、スライド、メモ、ブラウザなどです。

## ファイルを選ぶ

フォントは [ダウンロード](/#downloads) の欄か、[最新のリリース](https://github.com/antfu/furifont/releases/latest) から入手できます。[Furifont.zip](https://github.com/antfu/furifont/releases/latest/download/Furifont.zip) にはすべてのフォントが入っています。

ファミリーは 4 つあります。ゴシックと明朝で、それぞれふりがながひらがなのものとローマ字のものがあります。どのファミリーにも、2 種類のファイルがあります。

| ファイル | アプリでのファミリー名 | 太さ |
| --- | --- | --- |
| `FurifontSansVF.ttf` | Furifont Sans VF | ExtraLight から Heavy まで、すべての太さ |
| `FurifontSans-Regular.otf` | Furifont Sans | Regular のみ |

アプリがバリアブルフォントに対応しているなら、バリアブルフォント（`VF.ttf`）を選んでください。ふりがなも文字の太さに合わせて変わります。バリアブルフォントが表示されないアプリや、一つの太さしか表示されないアプリでは、`.otf` ファイルを使います。

`.woff2` ファイルはウェブサイト用です。パソコンにはインストールしません。[ウェブサイトで使う](/docs/website) を見てください。

## macOS

1. `.ttf` または `.otf` ファイルをダブルクリックします。Font Book が開きます。
2. **インストール** をクリックします。

ホームフォルダの `Library/Fonts` フォルダにファイルをドラッグしても入れられます。すべてのユーザーに入れるには、代わりに `/Library/Fonts` を使います。

## Windows

1. `.ttf` または `.otf` ファイルを右クリックします。
2. 自分だけに入れるなら **インストール**、すべてのユーザーに入れるなら **すべてのユーザーに対してインストール** をクリックします。

**設定 > 個人用設定 > フォント** にファイルをドラッグしても入れられます。Windows 11 では、メニューに **インストール** を出すために、先に **その他のオプションを確認** をクリックします。

## Linux

フォントのフォルダにファイルをコピーしてから、フォントのキャッシュを更新します。

```sh
mkdir -p ~/.local/share/fonts
cp FurifontSansVF.ttf ~/.local/share/fonts/
fc-cache -f
```

システムがフォントを見つけたか確かめます。

```sh
fc-list | grep Furifont
```

すべてのユーザーに入れるには、代わりに `/usr/local/share/fonts` にコピーします（`sudo` を使います）。

## インストールした後

- 開いていたアプリを再起動すると、新しいフォントが使えるようになります。
- 行の高さを十分に取ってください。ふりがなは漢字の上に付くので、行間が 1.6 くらいより狭いと、ふりがなが切れます。
- フォントを変えずにふりがなを隠すには、**スタイルセット 1** をオンにします。Windows 版の Word では **フォント > 詳細設定 > スタイルセット** にあります。macOS では、システムのフォントパネルを使うアプリの **タイポグラフィ** にあります。
- 言葉を別の読みで表示するには、[読みを選ぶ](/docs/readings) を見てください。
