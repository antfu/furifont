# 選擇讀音

很多詞有不只一個讀音。市場 可以讀作 いちば 或 しじょう，今日 可以讀作 きょう 或 こんにち。Furifont 顯示最常見的讀音。要顯示其他讀音，就在詞的第一個漢字後面緊接一個變體選擇器。

變體選擇器是看不見的字元。它留在文字中，所以在使用這款字型的任何應用程式和網站上都有效，複製文字時也會保留。

## 選擇器

| 選擇器 | 碼位 | 效果 |
| --- | --- | --- |
| VS241 | U+E01E0 | 無振假名 |
| VS242 | U+E01E1 | 讀音 1，即預設讀音 |
| VS243 | U+E01E2 | 讀音 2 |
| VS244 | U+E01E3 | 讀音 3 |
| … | … | … |
| VS256 | U+E01EF | 讀音 15 |

放在詞的第一個漢字後面時，選擇器選的是這個詞的讀音。放在單獨一個漢字後面時，選的是這個漢字的讀音。

::docs-example{text="市場"}
::

::docs-example{text="市\u{E01E2}場"}
::

::docs-example{text="今\u{E01E2}日"}
::

::docs-example{text="今\u{E01E0}日"}

## 查詢讀音編號

[參考](/reference) 依序列出了所有有多個讀音的詞和漢字。在那裡點選讀音，即可複製帶有選擇器的詞。

每個版本也以資料形式提供這些清單：`FurifontSansVF.ivs.json`，以及每個字型家族對應的同類檔案。

## 輸入選擇器

變體選擇器無法用鍵盤輸入。可以從 [參考](/reference) 複製，或寫成跳脫形式：

| 位置 | 市 + VS243 + 場 的寫法 |
| --- | --- |
| HTML | `市&#xE01E2;場` |
| JavaScript | `'市\u{E01E2}場'` |
| CSS `content` | `'市\E01E2場'` |

其他字型會忽略這些選擇器，所以文字在它們中看起來不變。

## 選擇器還是 CSS？

選擇器會改變文字內容。搜尋和複製時會多出一個字元，有些工具也會把它算進字數。在網站上，可以改用 CSS 選擇讀音，文字保持原樣：

```html
<span style="font-feature-settings: 'salt' 2">市場</span>
```

`'salt' 2` 的效果與 VS243 相同。請參閱 [在網站上使用](/docs/website#choose-a-reading)。
