## Rules that apply everywhere

- **MUST**, **MUST NOT**, **SHOULD** and **MAY** use RFC 2119 meanings. They mark
  real invariants - layer boundaries, wire contracts, output shapes - not house style.
- Before a PR, all gates MUST pass:
  `pnpm lint && pnpm build && pnpm typecheck && pnpm knip && pnpm test`
  (the app's types come from the packages' builds).
  Commits follow Conventional Commits.

## This project

- `@furifont/core` MUST NOT read font files and `@furifont/compiler` MUST NOT
  decide readings: the plan (`PlanSchema`) is the contract between them.
- Browsers shape one script run at a time, so rules only ever see kanji. Check
  rendering changes with `pnpm test:e2e` (three browsers), not HarfBuzz alone.
- `packages/dictionary/data/dictionary.json` and `places.json` are generated by
  `pnpm dict:update` and MUST NOT be edited by hand; curated defaults live in
  `packages/dictionary/src/defaults.ts`.
- `fonts/` is written by `pnpm release` and MUST NOT be edited by hand or
  replaced with local builds; the site serves it as committed.
- The app is Nuxt and UnoCSS: colors only through the `--ff-*` tokens in
  `uno.config.ts`, square corners, no `<style>` blocks.
